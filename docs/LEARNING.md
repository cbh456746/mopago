# 학습과 별도 평가

모파고는 21개 특징의 선형 가치함수와 빔 탐색을 결합한 정책입니다. 공간 특징·탐색 폭·전체 게임 정책 학습과 별도 평가에 계산량을 더 사용합니다.

## 추가 학습

~~~sh
npm run train -- 30 24 16
~~~

인수는 반복 횟수, 후보당 게임 수, 후보 수입니다. 기본 배포 모델을 시작 가중치로 쓰며 4번째 인수로 별도 시작 모델 파일을 지정할 수도 있습니다. 한 번의 기본 실행은 30 × 24 × 16 = **11,520게임의 후보 정책 플레이**입니다.

이번 학습은 기존 가치함수의 가중치에 새 공간 특징 6개의 초기값 0을 더해 시작했습니다. 공개된 최종 모델에서 명령을 다시 실행하면 그 가중치로 추가 학습하므로 이번 학습 과정을 처음부터 그대로 반복하는 것과는 다릅니다. 아래 별도 평가 명령은 공개된 최종 모델의 점수를 재현하는 용도입니다.

각 회차에서 시작 정책·현재 선택 정책·분포 평균과 대칭 가우시안 잡음 후보를 비교합니다. 상위 25% 후보를 이용해 가중치 탐색 분포를 갱신하는 cross-entropy 정책 탐색입니다. 환경의 게임 보상으로 정책을 최적화하는 강화학습 계열의 방법이며, 게임마다 신경망 역전파를 수행하는 방식은 아닙니다.

목적함수는 `log(평균/100000) + 0.15 × log(P90/130000)`입니다. 평균에 더 큰 비중을 주면서 상위 꼬리도 고려합니다. 할인율 0.985는 행동 탐색 내부에서만 사용합니다. 학습 목적 점수는 정상 종료한 게임의 할인하지 않은 최종 점수입니다.

후보 비교는 같은 회차의 시작 시드를 공유해 잡음을 줄입니다. 게임 시드는 `(seed + imul(gameIndex, 2654435761)) >>> 0`입니다. 회차별 24개 시작 환경을 여러 정책으로 실행하므로 **11,520개 모두가 서로 다른 난수 시드라는 뜻은 아닙니다**. 일반 배치·아이콘 생성·능력 획득·사용을 포함해 각 정책의 완전한 게임을 실제로 실행한 횟수입니다. 행동에 따라 난수 소비가 달라져 전체 추첨 시퀀스가 반드시 같지는 않습니다.

후보 선택은 별도의 내부 검증 100게임으로 수행합니다. 내부 검증은 반복해서 선택에 사용되므로 공개 성능의 독립 평가로 쓰지 않습니다. 이 검증 게임 수도 추가 학습 11,520게임에 합산하지 않습니다. 중간 후보·로그는 .local에만 저장하고 사이트나 공개 저장소에 올리지 않습니다.

## 특수능력과 탐색

훈련 환경에는 일반 조각 7회 배치마다 아이콘이 무작위로 나타납니다. 종류는 점 찍기 40%·바꿔 뽑기 60%이며, 아이콘 없는 빈 칸 중 위치를 추첨합니다. 보유 능력 7개·보드 아이콘 3개의 제한과 가장 오래된 아이콘 제거도 적용합니다.

첫 행동은 모든 적법 위치를 비교하고 빔 폭 12·최대 3행동을 탐색합니다. 재추첨은 가능한 결과의 확률 가중 가치로 평가한 뒤 탐색을 멈춥니다. 손패가 모두 소진되면 새 세 조각의 기대 크기를 가치함수에 반영하고 탐색을 멈춥니다. 이 근사는 모든 미래 손패의 완전 탐색과 다릅니다. 탐색을 이어가려 할 때 합법 행동이 없는 가지는 누적 보상만으로 비교합니다.

## 공간 특징의 추가 탐색

~~~sh
npm run tune
~~~

기본 정책 탐색의 최종 후보에서 1~2칸 빈틈에 대한 벌점을 따로 탐색합니다. 기존 가중치와 가로·세로 벌점 크기 `(1, 0.5)`, `(1.5, 0.75)`, `(2, 1)`, `(2.5, 1.25)`, `(3, 1.5)`, `(2, 0.5)`, `(2, 1.5)`를 비교합니다. 8후보 × 80게임 = **640게임**의 추가 정책 탐색이며, 시드 111303을 공유합니다. 점수 보상으로 가중치를 선택하는 탐색이며 별도 평가가 아닙니다.

기존 후보와 탐색 상위 두 후보는 새로운 내부 검증 시드 193011에서 각각 200게임으로 비교합니다. 검증 600게임은 학습 횟수에 합산하지 않습니다. 최종 후보에는 초기 탐색과 추가 탐색의 실행 횟수를 따로 기록합니다.

## 학습 후 평가

~~~sh
npm run evaluate -- .local/expert-candidate.json 500
~~~

최종 후보의 가중치를 고정한 뒤 학습·선택에 사용하지 않은 시드 1141003·1152009·1163017에서 각각 500게임을 실행합니다. 총 1,500게임입니다. 웹과 같은 추천 함수·탐색 설정·출현 가정을 사용합니다. 이 평가의 점수를 보고 후보를 다시 골라 같은 평가 점수를 독립 결과로 재사용하지 않습니다.

평균·중앙값·P90·최고·최저·13만 점 이상 횟수와 능력 사용·생성 집계를 기록합니다. P90은 정렬한 N개 점수 중 `ceil(0.9N)`번째 값입니다. 상위 10% 평균이 아닙니다. 게임당 안전 제한은 10,000행동이며, 제한에 도달한 게임이 있으면 반드시 그 수를 표시합니다. 정상 종료와 제한 종료를 혼동해 학습 완료 수를 부풀리지 않습니다.

## 결과 해석

평가 결과는 정확한 공식 출현 확률을 모르는 모의 환경의 결과입니다. 실게임에서 관측한 한 번의 점수나 관측 최고값만으로 평균 성능을 주장하지 않습니다. 목표 달성 여부는 평균 100,000점·P90 130,000점 기준 각각 따로 판정합니다.

CLI는 후보를 만들고 결과를 저장할 뿐 공개 모델을 자동으로 교체하지 않습니다. 새 후보를 배포하려면 규칙 검사, 같은 웹 정책의 별도 평가, 개인정보·공개 파일 검사를 먼저 수행하세요. 그 뒤 `npm run finalize`를 실행하면 학습 횟수·평가 정책의 해시·제한 종료 여부를 확인하고 default.json과 평가 문서를 함께 갱신합니다. 목표 미달인 경우에도 판정을 그대로 기록합니다.

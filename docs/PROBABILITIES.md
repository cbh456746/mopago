# 작은 조각의 완만한 감소 가정

단계가 올라갈수록 작은 조각이 덜 나오는 방향과 단계 경계는 공식 안내에 있습니다. 정확한 숫자 확률은 확인되지 않아 **모파고의 가정**을 공개합니다. 공식 출현 확률표가 아닙니다.

단계 s(1~5), 칸 수 k(1~10)에 대해 `r=0.6^((s-1)/4)`, `w=r^((10-k)/9)`를 계산합니다. 각 조각의 확률은 자신의 가중치를 19종 가중치 합으로 나눈 값입니다. 실제 코드는 가중치를 소수점 10자리로 반올림합니다. 동일 크기 조각에 차등 가중치는 주지 않습니다.

표는 소수점 4자리로 표시하므로 열의 표시값 합계는 반올림 오차가 있을 수 있습니다. 정확한 추첨은 정규화된 내부 값을 사용합니다. 1단계의 동일 가중치는 이 하나의 단계별 모델의 시작 조건이며, 모든 단계가 균등한 별도 모델은 제공하지 않습니다.

새 세 조각을 지급하거나 바꿔 뽑을 때 **현재 누적 제거 줄의 단계**를 사용합니다. 같은 세 조각을 사용하는 도중 단계가 올라가더라도 이미 지급된 조각은 바뀌지 않습니다. 동일 조각으로 재추첨되는 결과를 허용하며, 새 조각의 종류별 추첨은 복원 추첨을 가정합니다.

실제 확률이 다르면 가치함수·추천과 평가의 전제가 바뀝니다. 공식 수치나 신뢰할 수 있는 실제 관측 표가 확보되면 분포를 수정하고 재학습·별도 평가를 진행해야 합니다.

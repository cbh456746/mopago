# 규칙과 조각 표기

규칙을 바꾸면 학습 환경도 바뀝니다. 이 문서는 **공식 안내에서 확인한 사실**, **사용자가 제공한 사항**, **아직 확인하지 못해 둔 가정**을 분리합니다.

## 공식 안내에서 확인한 사실

출처는 [한글 모아모아 이벤트 안내](https://maplestory.nexon.com/News/Event/Ongoing/1393)이며 2026-10-01에 확인했습니다. 안내의 게임 설명과 점수표를 바탕으로 아래 내용을 정리했습니다.

| 항목 | 반영한 규칙 |
| --- | --- |
| 점수 | 일반 조각의 배치 칸 수만큼 점수 획득 |
| 가로줄 제거 | 동시에 지운 줄 수가 n이면 300 × n²점. 안내표의 1~5줄은 300, 1,200, 2,700, 4,800, 7,500점 |
| 능력 획득 | 획득한 능력당 50점 |
| 세 조각 | 세 조각을 모두 사용하면 새 세 조각을 받음 |
| 단계 | 누적 제거 줄이 0~30 / 31~60 / 61~100 / 101~150 / 151 이상일 때 1~5단계 |
| 단계별 확률 | 단계가 올라가면 칸 수가 적은 조각이 덜 나옴. 수치표는 확인되지 않음 |
| 아이콘 생성 | 일반 조각을 7회 배치할 때마다 빈 칸에 생성. 점 찍기 사용은 주기에 포함되지 않음 |
| 아이콘 종류 | 점 찍기 40%, 바꿔 뽑기 60% |
| 능력 보유량 | 두 종류 합계 최대 7개. 7개 보유 시 새 아이콘 생성 없음 |
| 보유량이 가득 찬 상태의 획득 | 줄을 지워도 능력을 얻지 못하며 아이콘은 보드에 남음 |
| 보드 아이콘 수 | 최대 3개. 새 아이콘으로 초과하면 가장 오래된 아이콘부터 사라짐 |
| 게임 종료 | 회전·반전으로도 조각을 놓을 수 없고 보유 능력이 없는 경우 종료 |
| 시간 | 별도 시간 제한 없음 |

화면에서 아이콘은 가장 오래된 것부터 입력하세요. 보유 능력과 보드 아이콘은 다릅니다. 아이콘을 입력하는 것만으로 보유 능력 횟수가 늘지는 않습니다.

## 사용자 제공 및 확인 사항

- 보드는 가로 10칸, 세로 16칸입니다.
- 채워진 가로줄만 사라집니다. 나머지 블록은 내려오지 않습니다.
- 회전과 좌우반전을 사용합니다. 두 조작을 조합하면 상하반전도 표현할 수 있습니다.
- 점 찍기는 원하는 빈 칸 하나를 채웁니다.
- 바꿔 뽑기는 선택한 보유 조각 하나를 다시 추첨합니다.
- 행 번호 1은 위쪽으로 해석합니다.
- 원래 크기 표기와 열별 표기가 다른 `ㅡ`와 `ㅅ`은 사용자 확인에 따라 열별 표기를 우선했습니다.

## 19개 조각

`columns`는 왼쪽 열부터 오른쪽 열까지 나열합니다. 예를 들어 `ㅏ`의 `["123", "2"]`는 첫 열의 1·2·3행과 둘째 열의 2행이 채워진 모양입니다. 회전·반전으로 동일해지는 모양은 중복 제거합니다.

## 미확정 사항과 모의 환경의 가정

| 미확정 항목 | 현재 구현 | 차이를 줄이는 방법 |
| --- | --- | --- |
| 단계별 조각 출현 확률 | 작은 조각이 단계별로 완만하게 감소하는 가정 하나. 정확한 수치는 공식 확률이 아님 | 공식 수치 확보 후 출현 규칙을 수정하고 재학습 |
| 아이콘 위치의 정확한 분포 | 다른 아이콘이 없는 빈 칸에서 균등 추첨 | 관측된 규칙에 맞춰 생성 로직 변경 |
| 점 찍기의 1칸 배치 점수 | 별도 배치 점수를 주지 않고 줄·능력 점수만 반영 | 실제 점수 변화 확인 후 수정·재학습 |
| 같은 조각으로 다시 뽑힐 가능성 | 동일 조각 결과도 허용 | 실제 제한 확인 후 추첨 함수 변경 |
| 능력 획득 시 초과 처리 순서 | 아이콘 입력 순서대로 보유량이 허용하는 만큼 획득 | 실제 초과 처리 관찰 후 수정 |
| 같은 행동에서 줄 제거와 아이콘 생성의 순서 | 줄 제거·능력 획득을 먼저 처리한 뒤 새 아이콘 생성 | 실제 동시 발생 상황을 확인한 뒤 수정 |

추천 중에는 무작위 새 아이콘을 특정 위치에 생긴 것으로 가정해 그리지 않습니다. 조각을 모두 사용한 뒤의 새 손패도 사용자에게 실제 결과를 입력받습니다. 학습 환경에서는 위 가정에 따라 무작위로 생성합니다.

전체 출현 가중치와 정규화한 확률은 [확률 문서](PROBABILITIES.md)에 공개했습니다. 화면에서는 실험 설정과 구모델 선택을 제공하지 않습니다. 새 조각이나 규칙을 추가하려면 소스를 변경하고 모델을 다시 학습·평가하세요.

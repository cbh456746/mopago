## 학습 조건

- 방법: 전체 게임의 보상으로 cross-entropy 정책 탐색.
- 초기 정책 탐색: 30회 × 16후보 × 24게임 = 11,520게임.
- 공간 특징 추가 탐색: 8후보 × 80게임 = 640게임. 합계 **12,160게임**. 시작 시드 111303.

- 탐색 난수 시드: 202610011. 후보끼리 같은 회차의 시작 게임 시드를 공유합니다.
- 초기 내부 검증: 시드 730031, 매 검사 100게임. 6,100회 게임 실행.
- 공간 특징 내부 검증: 시드 193011, 후보당 200게임, 합계 600게임. 기존 후보와 탐색 상위 후보 두 개를 같은 환경에서 비교했습니다. 선택 후보 번호 2.

- 내부 검증의 총 6,700게임은 학습 횟수·별도 평가에 합산하지 않습니다.
- 초기 선택 가중치: 21회차의 내부 검증에서 선택한 후보. 이후 공간 특징 추가 탐색을 거쳐 최종 가중치를 고정했습니다.
- 특징: 21개. 탐색 폭 12, 최대 3행동. 모든 적법 첫 행동을 비교합니다.
- 분포: 단일 완만한 감소 가정, 5단계 1칸/10칸 상대 가중치 0.6. [전체 확률표](PROBABILITIES.md).

## 평가 조건

- 총 1500게임, 각 시작 시드당 500게임.
- 게임별 난수는 시작 시드와 게임 번호로 분리하며 병렬 순서에 영향을 받지 않습니다.
- 웹과 동일한 추천 함수·분포·탐색 설정을 사용합니다. 미래 추첨 정보는 추천기에 전달하지 않습니다.
- 일반 배치 7회마다 무작위 아이콘, 점 40%·교체 60%, 보유·보드 제한을 적용합니다.
- 게임당 최대 10,000행동의 안전 제한. 제한 종료 0게임.
- P90: 정렬한 점수의 ceil(0.9 × N)번째 값. 상위 10% 평균이 아닙니다.

능력 아이콘은 점 24,192개·교체 36,319개가 생성됐고, 능력 43,122개를 획득했습니다. 점 찍기 17,168회, 바꿔 뽑기 25,954회를 사용했습니다.
